 Student Performance Dashboard

## 1. Project Overview

This project presents a Student Performance Dashboard created as part of Task 3 of the SWYNEX Technologies internship.

The dashboard provides a visual summary of student performance using KPIs and charts.

## 2. Dataset

- Dataset: Student Performance Dataset
- Rows: 395
- Columns: 33

## 3. Objective

The main objective is to create a professional dashboard that helps understand student performance, study time, failures, gender and attendance patterns.

## 4. Tool Used

- Microsoft Excel

## 5. Dashboard KPIs

- Total Students
- Average Final Grade
- Average Absences
- Maximum Final Grade

## 6. Charts

1. Students by Gender
2. Students by Study Time
3. Average Final Grade by Gender
4. Average Final Grade by Previous Failures
5. Student Age Distribution

## 7. Key Insights

1. The dataset contains 395 students.
2. The average final grade is 10.42.
3. The average number of absences is 5.71.
4. Male students have a slightly higher average final grade than female students.
5. Students with no previous failures have the highest average final grade.
6. More previous failures are generally associated with lower final grades.
7. Some students have unusually high absence values.

## 8. Conclusion

The dashboard provides a clear visual representation of student performance. It helps identify important patterns related to gender, study time, previous failures, age and final grades.
